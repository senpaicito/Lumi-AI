[ OVERVIEW ]
Project Companion is a locally hosted, autonomous AI entity that lives on
your computer and communicates via Discord DMs.

It features:
1. Psyche-Engine v3.1: A deep personality system (OCEAN traits, values).
2. Long-Term Memory: Uses Vector Database (ChromaDB) to remember facts.
3. Autonomy: Can natively initiate organic conversations if you haven't spoken in a while.
4. Admin Control: Complete remote control via Discord commands.
5. Advanced Tasks: Runs background routines overnight to maximize your hardware.

[ 2. INSTALLATION ]

1. Install Python 3.10 or newer.
 - Check "Add Python to PATH" during installation.

2. Install Ollama (https://ollama.com).
   - Run `ollama serve` in a terminal.
 - Run `ollama pull llama3` (or your preferred model).

3. Discord Setup:
   - Create a Bot in the Discord Developer Portal.
 - Enable "MESSAGE CONTENT INTENT" in the bot settings.
   - Copy the Token.
 - Get your User ID (Right click your name in Discord -> Copy ID).

4. Configuration:
   - Open `config.json`.
   - Paste your `bot_token`.
   - Paste your `allowed_user_id`.

5. First Run:
   - Double click `start_companion.bat`.
   - It will install dependencies automatically.
 - It will download the embedding model (first time only).
 - Wait for "✅ Logged in as..."

[ 3. DISCORD COMMANDS ]

These commands only work in DMs with the bot.

!ping
    Checks if the bot is online.
    Response: "Pong! (Latency)"

!status
    Shows the AI's current internal state.
    Displays: Mood, Energy, Intimacy Level.

!reset
    Wipes Short-Term Memory (RAM) only.
    Use this if the bot gets stuck in a loop or acts confused.
    Does NOT delete Long-Term memories or personality changes.

!force
    Manually triggers the Subconscious Analysis.
    Forces the bot to update its Mood/Intimacy based on the last few messages.

!fullreset
    WARNING: The Nuclear Option.
    Wipes EVERYTHING: Memories, Personality Growth, Relationships.
    Resets the AI to Day 1 Factory Settings.
    Usage: `!fullreset` -> `!fullreset confirm`

!edit [path] [value]
    "God Mode" - Edit the AI's brain directly from Discord.
    Usage: `!edit section.subsection.key value`
    
    Examples:
    - Change Name:   !edit core_identity.name Luna
    - Change Mood:   !edit dynamic_state.mood 100
    - Change Decay:  !edit dynamic_state.decay_rate 3.0
    - Change Voice:  !edit core_identity.voice_model "Sassy Pirate"

[ 4. MAINTENANCE & TIPS ]

BACKUPS:
The AI's "Soul" is located in the `data/` folder.
Copy this folder to a safe place once a week.
If the database corrupts,
you can just paste the backup folder back in.

CUSTOMIZATION:
Open `data/character_card.json` to change the base personality.
- "core_identity": Change who she thinks she is.
- "cognitive_profile": Change how smart/creative/anxious she is.
- "moral_compass": Change if she lies or tells the truth.

AUTONOMY:
The bot checks to message you every 60 seconds.
It will only message you if:
1. It is within "Awake Hours" (set in config.json).
2. It has been X hours since you last spoke.
3. It passes a random dice roll.

TROUBLESHOOTING:
- "AttributeError": You likely didn't update `bot.py` to the final version.
- "Ollama Connection Refused": Make sure Ollama is running (`ollama serve`).
- Bot ignores you: Check `allowed_user_id` in `config.json`.
