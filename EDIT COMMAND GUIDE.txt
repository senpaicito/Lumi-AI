Here is a complete guide to the `!edit` command based on the structure of your project.
The `!edit` command functions as "God Mode," allowing you to edit the AI's brain directly from Discord.
Because it edits the `character_card.json` file directly, the available "subcommands" correspond to the dot-separated paths of the JSON structure.

### Command Syntax

**Usage:** `!edit [path] [value]`
**Format:** `!edit section.subsection.key value`

*Note: The script automatically detects and converts standard data types like numbers and booleans (e.g., typing `true` or `100` will be formatted correctly in the code).*

---

### Master List of `!edit` Paths

#### 1. Core Identity (`core_identity`)
* `!edit core_identity.name [value]` (e.g., `!edit core_identity.name Luna`)
* `!edit core_identity.description [value]`
* `!edit core_identity.voice_model [value]`

#### 2. Dynamic State (`dynamic_state`)
Controls her current emotions, energy, and immediate situational awareness.
* `!edit dynamic_state.mood [number]` (e.g., `!edit dynamic_state.mood 100`)
* `!edit dynamic_state.energy [number]`
* `!edit dynamic_state.stress [number]`
* `!edit dynamic_state.context_buffer.last_topic [value]`
* `!edit dynamic_state.context_buffer.tension_level [value]`

#### 3. Relationship Depth (`relationship_depth`)
Manages how close she feels to you and what she calls you.
* `!edit relationship_depth.user_alias [value]`
* `!edit relationship_depth.intimacy_level [number]`
* `!edit relationship_depth.last_interaction [value]`

#### 4. Schedule (`schedule`)
* `!edit schedule.chronotype [value]`
* `!edit schedule.current_activity [value]`

#### 5. Arrays (Lists)
You can easily edit array lists by separating items with commas!
* `!edit personality [value, value, ...]`
* `!edit communication_style [value, value, ...]`
* `!edit important_rules [value, value, ...]`
* `!edit preferences.likes [value, value, ...]`
* `!edit preferences.dislikes [value, value, ...]`
